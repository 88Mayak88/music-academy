# Академия Музыки и Голоса

Готовый адаптивный сайт на HTML, CSS и JavaScript. Публичные файлы находятся в `dist/`.

## Запуск

Откройте `dist/index.html` в браузере либо запустите любой статический HTTP-сервер для папки `dist/`.
Сборка и установка зависимостей не требуются. Шрифты Manrope и Oswald загружаются из Google Fonts; доступны системные резервные шрифты.

## Что работает

- Мобильное меню и навигация по разделам.
- Пять карточек с подробностями программ.
- Переключение общего и предпрофессионального образования.
- Просмотр фотографии в увеличенном виде.
- Форма подготовки заявки через почтовое приложение и копирование текста.
- Кликабельные телефон и email, ссылки на тарифы и галерею исходного сайта.

## Заявки

Форма не отправляет данные на сервер и не сохраняет их. Она подготавливает письмо на jazzvidal20@gmail.com через `mailto:`. Посетитель самостоятельно отправляет письмо в своём почтовом приложении. Для автоматического приёма заявок нужно отдельно подключить почтовый сервис или CRM.

## Редактирование

- `dist/index.html` — разделы, основные тексты, контакты.
- `dist/styles.css` — оформление и адаптивные стили.
- `dist/app.js` — описания программ и интерактивные элементы.
- `dist/assets/` — все изображения.

`.openai/hosting.json` связывает исходники с приватным сайтом в Sites. Исходная страница на Tilda не изменялась.
